<assumption_delta>
The existing public-refresh assumption is that `phase13_acquire_publish_refresh()` can publish one candidate through `phase13_acquire_publish_accepted()` and update source registries separately, while the Plan 13-12 helper is handed an accepted root whose files are source-shaped. That assumption is invalid because the accepted root is already normalized in production.

Promote the primary representation explicitly: source-shaped tables are transient, trusted handoff inputs only; normalized CSVs are the sole accepted/publication representation. The current edition handoff comes from the validated in-memory candidate resources, and the companion edition handoff is rehydrated from its exact ignored raw JSON bundle plus source registry metadata. Both handoffs are written to an isolated staging root and passed to the existing normalized transaction; accepted normalized CSVs are never adapted backward into source-shaped tables. This preserves the existing one-edition capture/validation API for isolated replay while making the public two-edition refresh fail closed when either trusted source handoff is unavailable.
</assumption_delta>
