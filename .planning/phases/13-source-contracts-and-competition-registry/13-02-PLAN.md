<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| External structured UEFA resource -> local candidate | Untrusted source payloads and optional URL metadata enter deterministic validators. |
| Contributing official artifacts -> derived status artifact | Status fields cross a provenance projection boundary and must retain every source_artifact_id link. |
| Local raw bytes -> committed manifest rows | Exact bytes remain local while hashes and compact metadata enter Git. |
| Manual fallback metadata -> accepted bundle | Review claims and fallback status control a complete edition-wide publication. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-13-02-01 | Tampering | `R/competition/source_contracts.R` artifact hashing | high | mitigate | Compute exact byte count and SHA-256, validate every artifact row, and recompute canonical bundle/manifest hashes before acceptance. |
| T-13-02-02 | Repudiation | Explicit and derived status provenance | high | mitigate | Persist explicit URL lineage or sorted source_artifact_id links, retrieval time, parser Git SHA, hashes, and review state for every status artifact. |
| T-13-02-03 | Spoofing | Structured-only resource gate | high | mitigate | Validate JSON structure and reject rendered HTML, PDF, prose, and missing status-bearing fields. |
| T-13-02-04 | Tampering | Reviewed fallback metadata | high | mitigate | Require edition-wide fallback status, complete operator/review fields, and reject mixed official/fallback artifacts. |
