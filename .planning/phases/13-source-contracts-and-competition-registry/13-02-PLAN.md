<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Operator-supplied source URL -> capture script | URL and response bytes may be malformed, non-structured, or unexpectedly large. |
| Manual fallback bundle -> accepted metadata | Human-reviewed fallback data can be incomplete or mixed with official rows. |
| Candidate accepted output -> committed registry files | Invalid candidate rows could replace the last accepted contract. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-13-06 | Tampering | `scripts/acquire_uefa_snapshot.R` capture inputs | high | mitigate | Accept only explicit structured resource types and validate required classes, schemas, hashes, and parser Git SHA before acceptance. |
| T-13-07 | Information Disclosure | Exact raw response store | medium | mitigate | Keep exact bytes under ignored local raw storage and commit only compact manifests and normalized artifacts. |
| T-13-08 | Repudiation | Manual fallback metadata | medium | mitigate | Require source, retrieval date, reason, operator note, checksum, review_state, and fallback_status on every fallback bundle. |
| T-13-09 | Denial of Service | UEFA schema drift | medium | mitigate | Fail closed with blocked failure metadata and retain last accepted output instead of publishing a partial candidate. |
| T-13-SC | Tampering | npm/pip/cargo installs | low | accept | No package-manager install tasks exist; Phase 13 uses base R, digest, jsonlite, and testthat already available locally. |
</threat_model>
