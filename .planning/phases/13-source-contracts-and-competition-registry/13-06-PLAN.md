## Trust Boundaries

| Boundary | Description |
|---|---|
| Candidate capture error -> edition registry | Error reason, timestamp, and batch identity become durable operational state. |
| Staged competition_editions.csv -> durable registry | A blocked row replaces the prior authority only after full validation. |
| Blocked edition -> refresh-batch sidecar | Batch status and candidate/accepted lineage must agree with the edition row. |
| Blocked edition -> operator recovery | A blocked lifecycle state must not be cleared by an implicit successful refresh. |
| Accepted output -> failure metadata | Sidecar metadata must point to the output that remains active. |
