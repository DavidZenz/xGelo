## Trust Boundaries

| Boundary | Description |
|---|---|
| Candidate capture error -> edition registry | Error text and timestamps become durable operational state. |
| Staged registry copy -> committed competition_editions.csv | A validated candidate registry replaces the prior authority atomically. |
| Blocked edition -> operator recovery | A blocked lifecycle state must not be cleared by an implicit successful refresh. |
| Accepted output -> blocked sidecar | Failure metadata must point to the output that remains active. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-13-06-01 | Tampering | blocked registry overlay | high | mitigate | Build the blocked row with phase13_block_competition_edition(), recompute row hash, validate a temporary copy, then atomically publish. |
| T-13-06-02 | Denial of Service | failed candidate publication | high | mitigate | Never replace accepted output or source registries until candidate and registry validation pass; retain the previous accepted tree on errors. |
| T-13-06-03 | Repudiation | blocked_refresh.json and audit fields | medium | mitigate | Record reason, UTC timestamp, parser SHA, registry revision, and both source/output last-accepted linkages in the sidecar and registry. |
