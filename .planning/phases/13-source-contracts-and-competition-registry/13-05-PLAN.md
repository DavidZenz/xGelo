Close the G-13-03 loader gap: the edition loader currently validates registry CSVs and source bundles but never inspects accepted snapshot directories, while the default identity loader omits source-bundle foreign-key validation.

Purpose: Make the durable loaders enforce the full accepted-snapshot contract before Phase 14 or refresh code can consume an edition or identity registry.
Output: Accepted-directory validation integrated into the production edition loader, default identity provenance validation, and temporary-copy regressions for missing, tampered, and forged-linked artifacts.
</objective>
