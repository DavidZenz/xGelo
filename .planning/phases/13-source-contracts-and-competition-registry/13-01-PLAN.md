## Trust Boundaries

| Boundary | Description |
|---|---|
| External structured UEFA resource -> local candidate fixture | Untrusted source payload and metadata enter local contract code. |
| Local raw bytes -> committed manifest rows | Exact bytes remain local while hashes and compact normalized artifacts enter Git. |
| Source team identity -> xGelo team_id | Untrusted source names and IDs resolve to durable internal identity. |
| Accepted source bundle -> competition edition registry | Bundle identity controls later state and publication phases. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-13-01 | Tampering | `R/competition/source_contracts.R` raw artifact hashing | high | mitigate | Compute byte count and SHA-256 from exact raw bytes and verify every artifact row before bundle acceptance. |
| T-13-02 | Repudiation | Bundle and artifact provenance rows | medium | mitigate | Persist source URL, retrieval time, parser Git commit SHA, fallback status, and manifest self-hash on accepted rows. |
| T-13-03 | Spoofing | `R/competition/team_identity.R` source display-name fallback | high | mitigate | Prefer UEFA source ID, require deterministic exact normalized alias fallback metadata, and fail ambiguous identity matches. |
| T-13-04 | Tampering | Manual fallback path | high | mitigate | Require edition-wide fallback status and complete reviewed fallback metadata; reject mixed official/fallback bundles. |
| T-13-05 | Denial of Service | Candidate schema drift | medium | mitigate | Reject incomplete or drifted candidates while retaining last accepted bundle metadata for downstream consumers. |
| T-13-SC | Tampering | npm/pip/cargo installs | low | accept | No package-manager install tasks exist; Phase 13 reuses local R packages already present. |
