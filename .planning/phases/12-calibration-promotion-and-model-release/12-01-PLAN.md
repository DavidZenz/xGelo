## Trust Boundaries

| Boundary | Description |
|---|---|
| Benchmark predictions/fixtures → calibration service | Candidate rows, dates, labels, and probabilities are untrusted inputs to a fitting transform. |
| Calibration recipe JSON → optimizer | Recipe bytes control the transformation and must be frozen and hashed before fitting. |
| Calibrator output → later scoring/release stages | Derived 1X2 values must not alter the fitted score distribution or bypass holdout guards. |
