## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Model adapter → common contract | Model-specific output is untrusted until complete-grid, fixture, manifest, and coverage validation passes. |
| Optional restricted snapshot → feature-rich panel | Local restricted inputs may inform declared features but raw data must not enter public/open-core bundles. |
