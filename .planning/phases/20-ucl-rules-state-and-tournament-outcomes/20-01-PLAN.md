<objective>
Establish the production-quality vertical tracer for the UCL rules/state/outcomes pipeline, proving one accepted fixture-authority path through every Phase 20 layer while production remains fail-closed behind the repaired Phase 19 authority boundary.

Purpose: This is the architecture proof that later rule, simulation, reconciliation, and orchestration expansions can extend without inventing a second source, score, identity, or release contract.
Output: Editioned UCL rules/evidence, state/simulation/outcome seams, reusable full-cardinality fixture helpers, and a passing deterministic tracer with explicit fixture-versus-production authority.
</objective>

## Trust Boundaries

| Boundary | Description |
|---|---|
| Phase 18 accepted/fixture source → UCL state | Untrusted source rows cross into the schedule, identity, lifecycle, and score validator. |
| Phase 19 resolver → forecast ledger | Club-release authority and typed parent evidence decide whether a forecast can be durable. |
| Fixture roots → outcome candidate | Temporary mechanics evidence must not cross into production selector or incumbent state. |
| R data frames → canonical hashes | Input order, timestamps, and serialization choices can alter identity if not normalized. |
