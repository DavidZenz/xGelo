## Trust Boundaries

| Boundary | Description |
|---|---|
| Phase 18 accepted/fixture source → UCL state | Untrusted source rows cross into the schedule, identity, lifecycle, and score validator. |
| Phase 19 resolver → forecast ledger | Club-release authority and typed parent evidence decide whether a forecast can be durable. |
| Fixture roots → outcome candidate | Temporary mechanics evidence must not cross into production selector or incumbent state. |
| R data frames → canonical hashes | Input order, timestamps, and serialization choices can alter identity if not normalized. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T20-01-01 | Tampering | schedule/state validator | critical | mitigate | Require exact 36-club/144-fixture graph, endpoint/venue/kickoff/score/lineage checks, and no inferred edges before standings. |
| T20-01-02 | Elevation of privilege | Phase 19 release handoff | critical | mitigate | Call the final fixed production resolver and typed parent graph internally; mark fixture authority non-promotable and reject selector creation. |
| T20-01-03 | Tampering | tracer/outcome hashes | high | mitigate | Canonical-v2 row/table hashes, semantic ordering, explicit seed, and reversed-input replay assertions. |
| T20-01-04 | Information disclosure | source/release metadata | medium | mitigate | Persist authority IDs, hashes, and attribution only; keep credentials and authenticated transport state process-local. |
