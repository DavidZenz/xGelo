## Trust Boundaries

| Boundary | Description |
|---|---|
| Completed/open state → sampler | Lifecycle and forecast status decide which fixtures are fixed versus stochastic. |
| Rank intervals → draw path generator | Unresolved or boundary-crossing ranks can change legal pair families and bracket positions. |
| Manual/accepted draw artifact → simulation | Edition, source lineage, completeness, and hash decide whether exact conditioning is allowed. |
| RNG → canonical outcome rows | Seed and input order must not create hidden identity drift. |
