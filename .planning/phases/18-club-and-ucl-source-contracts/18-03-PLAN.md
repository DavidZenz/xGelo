<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| process-local credential → provider request | Secret-bearing authentication enters an outbound HTTPS request. |
| provider response/redirect → adapter | Remote bytes, status, headers, final URL, JSON shape, nulls, and enum values are untrusted. |
| provider IDs → club registry | Remote identities request canonical club mappings. |
| probe evidence → accepted-manifest writer | Local evidence may be tampered, reordered, or partially written. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T18-01 | Information Disclosure | authenticated request | high | mitigate | Redacted process-local header, no request serialization, exact-token scans, and non-secret return contract. |
| T18-02 | Spoofing / Information Disclosure | URL and redirects | high | mitigate | Fixed HTTPS base, endpoint templates, final-host verification, and rejection of caller-supplied hosts/paths. |
| T18-03 | Tampering | probe evidence | high | mitigate | Exact raw SHA-256, schema/coverage hashes, reviewed expectation hash, and atomic accepted-manifest installation. |
| T18-04 | Tampering / Denial of Service | null/empty/stale/partial responses | high | mitigate | Lifecycle-aware cardinality/freshness/schema/enum/pagination gates; candidate only, no promotion in this plan. |
| T18-05 | Tampering | provider club identity | high | mitigate | Every club and match participant resolves through the Plan 18-02 registry; ambiguity/cross-domain matches block. |
| T18-06 | Denial of Service | retries and quota | medium | mitigate | Four logical competition calls, nine-per-minute throttle, three bounded attempts, Retry-After support, and no per-ID crawl. |
| T18-16 | Tampering / Elevation of Privilege | first live acceptance | high | mitigate | Separate no-cache probe, fixed endpoint plan, complete owner review, expectation-bound matrix, identity coverage, secret scan, and atomic manifest write before ordinary live mode can run. |
| T18-SC | Tampering | package supply chain | low | accept | No package installation task; installed official R packages and existing helpers are used. |
</threat_model>
