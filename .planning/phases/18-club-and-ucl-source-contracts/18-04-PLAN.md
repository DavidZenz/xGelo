<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| candidate tree → accepted tree | Untrusted candidate bytes attempt to replace durable state. |
| concurrent/interrupted process → transaction roots | Competing or terminated processes can leave partial files. |
| provider terms decision → retained state | Compliance state may revoke automation or retention authority. |
| error input → durable blocked record | Raw remote errors may contain secrets or unstable text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T18-03 | Tampering | accepted tree | high | mitigate | Complete bundle validation, exact target inventory, trusted roots/no symlinks, snapshots, staged promotion, read-back, and rollback. |
| T18-04 | Tampering / Denial of Service | invalid candidate | high | mitigate | Full typed failure matrix; no invalid candidate reaches promotion. |
| T18-12 | Denial of Service / Tampering | concurrency and interruption | high | mitigate | Exclusive lock, stale-lock rules, signal-safe cleanup hooks, deterministic target order, and byte restoration tests. |
| T18-07 | Repudiation | provider exit/terms change | high | mitigate | Current review/terms hash is checked before transport; reviewed retain and withdraw are separate atomic branches with retention permission, tombstone, inventory, rollback, and reviewer hashes. |
| T18-01 | Information Disclosure | blocked diagnostics | high | mitigate | Stable reason codes and sanitized fields only; no raw authenticated request/response text in durable records. |
| T18-18 | Tampering / Elevation of Privilege | promotion authority | high | mitigate | Recompute the closed source-mode authority union at promotion; require matching accepted provider/manual ID and hash; reject fixture and mixed variants unconditionally. |
| T18-SC | Tampering | package supply chain | low | accept | No package installation occurs. |
</threat_model>
