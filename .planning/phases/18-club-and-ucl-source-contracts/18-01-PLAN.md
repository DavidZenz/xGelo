<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| operator environment → acceptance CLI | Credential presence and operator-selected evidence paths enter a local process; only the bounded acceptance probe may cross the network boundary before automation is enabled. |
| owner review CSV → machine decision | Human legal/business judgments are untrusted structured input until schema and hash validation pass. |
| concurrent process → durable manifest | Multiple or interrupted runs contend for one decision artifact. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T18-01 | Information Disclosure | `accept_ucl_provider.R` | high | mitigate | Read only credential presence above the network boundary; token handling lives in Plan 18-03; reject token CLI args and scan durable outputs. |
| T18-02 | Spoofing | CLI options | high | mitigate | Fixed provider ID and no host/path/token arguments; strict option allowlist. |
| T18-07 | Repudiation | owner terms review | high | mitigate | Hash the exact review, terms URL/hash, reviewer, time, and application scope into the manifest; a terms change invalidates approval. |
| T18-08 | Tampering | concurrent/interrupted manifest write | high | mitigate | Exclusive lock, sibling staging, atomic rename, exact incumbent snapshot, cleanup, and same-ID collision rejection. |
| T18-16 | Tampering / Elevation of Privilege | first live acceptance | high | mitigate | Separate no-cache `live_acceptance_probe`, complete owner review, fixed four-endpoint allowlist, expectation-bound machine matrix, secret scan, staged validation, and atomic manifest creation; ordinary live ingestion remains gated. |
| T18-SC | Tampering | package supply chain | low | accept | No npm/pip/cargo or new R package installation occurs; only already installed, repository-used packages are called. |
</threat_model>
