<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| remote Git source → local raw checkout | Repository contents, commit/path claims, and licenses are untrusted until pinned and verified. |
| historical names/scores → canonical matches | Identity, duplicate, score, and time semantics may be ambiguous. |
| local paths → audit/accepted roots | Traversal, symlink, mutation, and partial-write risks cross the filesystem boundary. |
| audit manifest → Phase 19 | A forged eligibility boolean could admit unsafe training rows. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T18-03 | Tampering | source/audit artifacts | high | mitigate | Full commit/path/raw hashes, row/component/corpus/self-hashes, fresh-process recomputation, and immutable inventory. |
| T18-05 | Tampering | club identity | high | mitigate | Plan 18-02 resolver, event-time validity, 100 percent active-row resolution, and cross-domain rejection. |
| T18-06 | Tampering | training eligibility | high | mitigate | Exact zero-defect/unit-fraction/coverage-equality gates are recomputed; stored `accepted_for_training` is never trusted. |
| T18-13 | Repudiation | license/coverage review | high | mitigate | Reviewer, time, license URL/hash, expected count, and disposition are durable and hash-bound; missing review blocks. |
| T18-14 | Tampering / Information Disclosure | paths and symlinks | high | mitigate | Safe relative paths, root containment, no symlinks, declared inventory only, ignored raw root, and atomic sibling writes. |
| T18-15 | Tampering | duplicate/score/time semantics | high | mitigate | Separate audit tables, explicit dispositions, split score fields, conservative evidence time, and no unresolved active rows. |
| T18-17 | Spoofing / Tampering | historical identity bootstrap | high | mitigate | Inventory-derived token evidence, explicit owner mappings and validity intervals, unresolved ledger, atomic registry merge, and exact identity-coverage rerun. |
| T18-SC | Tampering | package supply chain | low | accept | No package installation occurs; Git and installed R packages are already established project dependencies. |
</threat_model>
