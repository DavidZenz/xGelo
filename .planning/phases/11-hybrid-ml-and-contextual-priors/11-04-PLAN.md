<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Current xG/form files -> activation gate | Existing columns must not imply active historical xG signal. |
| Structural source snapshots -> model prior | Slow-moving external variables can leak future values into historical folds. |

## Phase-Wide Risk Coverage

| Risk | Applicability | Plan Treatment |
|------|---------------|----------------|
| Historical leakage | applicable | xG and structural validators enforce point-in-time coverage, variance, provenance, source year, source date, and evidence cutoff rules. |
| Silent activation | applicable | xG remains inactive unless thresholds pass; structural shrinkage refuses unregistered or checksum-mismatched source snapshots. |
| Restricted-data redistribution | not applicable | Structural sources are open World Bank/CEPII/Natural-Earth-style inputs; no squad or bookmaker raw rows are published. |
| Registry/bundle drift | applicable | Gate manifest, structural prior manifest, source snapshot checksums, and row hashes are registered before evaluation. |
| Manual snapshot contamination | applicable | Committed structural source CSVs require vintage, source, license, parent checksum, canonical row hash, and rejection of current/latest unregistered files. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
