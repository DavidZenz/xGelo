## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| registered source manifest/config -> activation validator | Future UEFA artifact paths, raw bytes, provenance, IDs, hashes, and timestamps are untrusted until the complete bundle contract passes. |
| candidate revision -> accepted state | A correction must not alter accepted content while validation is incomplete or failed. |
| activation envelope -> forecast consumers | Downstream code must receive explicit lifecycle/reason and empty/suppressed collections when prerequisites are absent. |
