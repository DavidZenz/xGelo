<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| match evidence -> ranking | Results, group membership, and home/away evidence are untrusted until identity and completeness checks pass. |
| host association -> place capacity | Host guarantees and direct qualification can conflict; the allocation ledger is the control point. |
| rules/source revision -> topology | A changed or incomplete official rule source must not select a topology by convention. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-06 | Tampering | `rank_euro_group()` and `rank_euro_overall()` | high | mitigate | Validate stable team/group identities, preserve evidence/exclusion IDs, and use the explicit official tie-break order. |
| T-16-07 | Tampering | `allocate_euro_places()` | critical | mitigate | Apply direct, host, best-runner-up, and play-off capacity in a single conservation ledger with host-first consumption. |
| T-16-08 | Spoofing | host association rows | high | mitigate | Require source-lined host associations and expose occupied/unused/unresolved status rather than trusting display labels. |
| T-16-09 | Denial of Service | incomplete comparison groups | medium | mitigate | Bound comparisons to declared groups and return typed unavailable/unresolved states when required evidence is absent. |
| T-16-10 | Repudiation | topology and rules revision | medium | mitigate | Attach canonical ruleset/source revision metadata and deterministic hashes to every topology/allocation result. |
</threat_model>
