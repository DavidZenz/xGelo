## Resolution

root_cause: The previously published bundle was generated by the pre-fix projected-standings reducer, which emitted only the currently observed rank for each team and assigned probability 1. The local corrected reducer and generated payload were initially uncommitted, so GitHub Pages continued serving the stale 54-row artifact. The renderer was not the source of the collapse.

fix: Regenerated the Nations League outcomes with the complete team-by-rank matrix, preserved fractional rank/path probabilities, validated probability conservation, and promoted the corrected dashboard route. The live route now exposes 210 projected-outcome rows with non-degenerate probabilities.

verification: Public payload read-back confirmed 210 projected standings rows and the expected fractional cells. Existing Phase 15 regression assertions cover team/rank mass, matrix dimensions, fractional cells, and future-fixture sensitivity. The full Phase 15 file still reports unrelated pre-existing fixture-state/simulation-count failures against the current in-progress accepted snapshot; those failures were not introduced by this fix.

guardrail: phase15_nl_validate_probability_groups now rejects collapsed projected standings by requiring every team/rank cell and conserved team/rank probability mass before publication.
