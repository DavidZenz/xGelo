xGelo: Free Elo + xG Forecasting for UEFA World Cup Qualifiers

This notebook demonstrates the complete xGelo pipeline from raw data to forecast generation. All code is reproducible and can be run end-to-end.

1. Project Overview

The xGelo system forecasts UEFA World Cup Qualifier matches using: - xG Model: Predicts shot quality using StatsBomb event data - Elo Ratings: Computes team strength ratings from historical results - Integration Layer: Combines xG and Elo into form metrics - Forecast Models: Negative Binomial models for goal prediction - Monte Carlo: Simulates match outcomes

Key Metrics

  • xG Model AUC: 0.7905 (trained on domestic league data)
  • Elo System: 49,368 matches, 336 teams, 1872-present
  • Forecast Brier Score: < 0.25 (calibrated)

9. Model Card

For complete model documentation, see MODEL-CARD.md.

Key Specifications

  • Model Type: Logistic Regression (xG), Negative Binomial (goals)
  • Version: 1.0
  • License: MIT
  • Intended Use: UEFA World Cup Qualifier forecasting

Performance Metrics

  • xG Model AUC: 0.7905
  • Forecast Brier Score: < 0.25
  • Draw Probability: ~28% (calibrated for WCQ-UEFA)

Training Data

  • xG Model: StatsBomb Open Data events (domestic leagues)
  • Elo System: 49,368 international matches (martj42)
  • Forecast Models: martj42 international results

Features

xG Model: - distance: Shot distance from goal (yards) - angle: Shot angle to goal (radians) - header: Is header shot (logical) - open_play: Is open play (logical) - competition: Competition name (factor)

Forecast Models: - elo_diff: Elo rating difference (home - away) - xgf_ewma: Home team xG For EWMA - xga_ewma: Home team xG Against EWMA - non_neutral_home: Non-neutral venue (logical) - rest_diff: Rest days difference (home - away)

Limitations

  • xG model trained on domestic leagues only
  • Forecast models use historical international data
  • No live data support (pre-match only)
  • Assumes standard pitch dimensions (StatsBomb: 120x80 yards)
